# Chess

Play chess directly inside RuneLite while playing Old School RuneScape.

## Features

* Local chess
* Play against RuneScape-themed bots
* Private matches with invite codes
* Unrated online matchmaking

## Varrock Chess Club

The chess board inside **Varrock Castle** can be used as the multiplayer hub.

Right-click it to:

* **Find opponent** — join an unrated matchmaking queue
* **Private match** — create or join a match with a friend
* **Play Chess** — open the Chess Club menu

Matchmaking automatically pairs players using the same time control and opens the in-game chess board when a match is found.

Private matches use a temporary invite code that you can share with a friend.

## Installation

Install **Chess** from the RuneLite Plugin Hub.

Then open the Chess sidebar or visit the chess board in Varrock Castle.
